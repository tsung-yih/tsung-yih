一般閥類與管道配件總覽

提供全系列建築給排水、消防與工業管道閥門，一站式滿足工程備料需求

🏢 一站式管道閥門供應服務

總毅實業備有齊全的常備閥件庫存，涵蓋多種材質、壓力等級與連接方式。無論是零星補充或全案工程備料，均能為您提供最專業快速的對應。

🚪 開關閥類

  • 閘閥 (Gate Valve) 昇桿 / 暗桿 / 溝槽
  • 球閥 (Ball Valve) 兩片式 牙口 / 法蘭口 / 溝槽
  • 蝶閥 (Butterfly Valve) 對夾式 / 齒輪式 / 手把式 / 溝槽

🔄 逆止閥與過濾類

  • 靜音逆止閥 (Silent Check Valve) 揚水泵浦出口專用
  • 直立式緩衝逆止閥 (Dual Plate Check) 體積小 / 低水頭損失
  • 橫式逆止閥 (Swing Check) 經典耐用 / 牙口與法蘭
  • 底閥 (Foot Valve) 泵浦吸入端防回流
  • Y型過濾器 (Y-Strainer) 保護後端閥件設備 牙口 / 法蘭口 / 溝槽

🚽 排水系統專用閥類

  • 偏心式制水閥 (Eccentric Plug Valve) 污廢水專用
  • 彈性版逆止閥 (Flex Disc Check Valve) 排水防倒流

💨 排氣與氣體控制閥類

  • 自動排氣閥 (給水系統專用) 排除管路積氣 / 防止氣鎖現象
  • 消防專用排氣閥 消防管網充水快速排氣
  • 水箱浮球閥 (Float Valve) 不鏽鋼球 / 精準液位控制

🔧 消防機械與高壓另件

  • 消防機械接頭另件 (Grooved Fittings) 溝槽式彎頭 / 三通等 /
  • 不鏽鋼 300PSI 耐高壓另件 高層建築與高壓管路專用

❄️ 保溫另件與驅動控制

  • 管道保溫另件與專用配件 防止冷凝結露 / 保持管路溫控
  • 電動驅動閥 (Electric Actuated Valve) 牙口 / 法蘭口
全系列閥件通用規格範圍
主要材質 鑄鐵 (Cast Iron)、球墨鑄鐵 (Ductile Iron)、不鏽鋼 (SUS304)、砲金銅 (Bronze)
適用口徑範圍 1/2" (DN15) 至 12" (DN300) 以上（依閥型而定）
壓力等級 JIS 10K / 16K, ANSI 150LB / 300LB, PN10 / PN16 （依閥型而定）
連接方式 牙口 (BSPT)、法蘭口 (Flanged)、對夾式 (Wafer) 、溝槽 (Grooved)（依閥型而定）
適用場所 高層建築給排水系統、消防水務工程、工業廠房水路各類水電基礎建設。
